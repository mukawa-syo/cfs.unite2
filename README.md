cfs.unite2 — Laravel Crowdfunding System

このリポジトリは、Laravel を使用して開発しているクラウドファンディングシステムの個人開発プロジェクトです。
学習を進めながら、実務に近い構成・機能設計を意識して開発しています。

🚀 開発目的

フルスタック開発の理解を深めるため

Laravel を用いた MVC 構造の理解・活用

認証・決済・データ管理といった、実務で必要な機能の実装

AWS（EC2 / SES / Route53 など）との連携を含む、デプロイ・運用の基礎構築

🛠 使用技術
Backend

PHP 8.x

Laravel 10.x

Composer

Frontend

Blade

Bootstrap

Infrastructure

AWS EC2（本番環境）

Amazon Linux 2023

Apache / PHP-FPM

Route53

Amazon SES（メール受信・転送設定）
